# Linux Infrastructure Home Lab

A hands-on virtualized Linux infrastructure environment designed to develop practical skills in Linux system administration, networking, security, automation, and troubleshooting.

## Project Goals

* Develop practical Linux system administration skills
* Configure and troubleshoot network services
* Implement basic Linux security controls
* Practice remote server administration
* Automate common administrative tasks with Bash
* Simulate and troubleshoot infrastructure failures
* Document technical configurations and troubleshooting procedures

## Planned Technologies

* Ubuntu Server
* VirtualBox / VMware
* Linux SSH
* Nginx
* UFW
* Fail2ban
* DNS
* Bash
* Git / GitHub
* Linux networking and troubleshooting tools
