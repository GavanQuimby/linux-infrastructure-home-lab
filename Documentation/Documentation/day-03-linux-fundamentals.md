## Objective

Develop foundational Linux system administration skills using the LAB-WEB01 Ubuntu Server.

## Topics Covered

* Linux filesystem structure
* Directory navigation
* File creation and management
* Users and groups
* Administrative privileges
* File permissions
* File ownership

Reviewed the purpose of common directories including:

* `/home`
* `/etc`
* `/var`
* `/tmp`
* `/usr`
* `/root`
* `/boot`

## User Administration

Created a secondary administrative user named `technician` and added the account to the `sudo` group.

## Permissions

Practiced Linux permissions using `chmod` and file ownership using `chown`.

Successfully practiced fundamental Linux administration tasks and gained familiarity with the Linux filesystem, users, groups, permissions, and file management.
